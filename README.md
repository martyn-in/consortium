# CONSORTIUM 2026 — Annual National Tech Summit

> **A luxury royal futuristic web experience for the flagship annual technical fest of Institute of Aeronautical Engineering (IARE), Hyderabad.**

![Consortium 2026 Preview](https://raw.githubusercontent.com/martyn-in/consortium/main/src/assets/hero_orb.jpg)

---

## 🏛️ Overview

**CONSORTIUM 2026** is designed as a royal futuristic national technology event website inspired by Apple keynotes, prestigious award ceremonies, and cyber palace aesthetics.

- **Theme Palette**: Deep Black (`#04060d`), Royal Navy (`#0b1329`), Metallic Gold (`#d4af37`, `#fef08a`), Sapphire Blue Glow, and Palace Amethyst highlights.
- **Typography**: Regal luxury serifs (**Cinzel** & **Playfair Display**) paired with modern sans-serifs (**Plus Jakarta Sans** & **Inter**).
- **Audio & Ambient Experience**: Integrated procedural sound synthesis and ambient aurora background video.

---

## ✨ Features & Components

- **Floating Glass Navbar**:
  - Enters on page load with gold crown brandmark, Cinzel typography, and animated active underline.
  - Controls for ambient party background video playback and interactive sound effects.
- **Cinematic Hero Section**:
  - Master title `CONSORTIUM 2026` with metallic gold gradient, animated shine sweep, and letter-by-letter reveal.
  - 4 glass information cards: *Royal Dates*, *Host Palace*, *Flagship Events*, and *National Delegates*.
  - Metallic gold 3D lift primary button with magnetic cursor pull and ripple click.
- **Luxury Digital Flip Countdown**:
  - High-precision live countdown dials with gold glowing digits and breathing pulse animation.
- **Battleground Arenas (Events Section)**:
  - Responsive cards with real-time 3D tilt physics, dynamic gold cursor spotlight, and equal height enforcement.
  - Category filters: *Coding & AI*, *Robotics & Hardware*, *Esports*, and *Creative Media*.
- **Architects of Innovation (About Section)**:
  - Split layout featuring an imperial showcase card with orbital rotating rings and NAAC A++ accreditation seal.
  - Editorial narrative with gold divider lines and Roman-numeral pillars.
- **Imperial Conclave Timeline (Schedule)**:
  - Interactive day switchers (Day 1 / Day 2), gold-to-sapphire central timeline spine, and glowing node pins.
- **Strategic Alliances (Sponsors Section)**:
  - Title partner spotlight card and continuous smooth logo marquee with glass chip containers.
- **Sovereign Festival Pass Generator (PassModal)**:
  - Generates personalized digital delegate passes with gold microchips, barcodes, and QR codes.
  - Finishes: *Imperial Gold*, *Royal Sapphire*, and *Palace Amethyst*.
  - Confetti burst on credential claim.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Animations**: Framer Motion & GSAP
- **Icons**: Lucide React & Inline Optimized SVGs
- **Celebration Effects**: Canvas Confetti
- **Audio Engine**: Web Audio API Sound Synthesizer
- **Linter**: Oxlint

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/martyn-in/consortium.git

# Navigate to project folder
cd consortium

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
